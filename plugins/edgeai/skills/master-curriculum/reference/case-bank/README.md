# Edge AI Case Bank

This folder holds sanitized Edge AI client case material for lesson examples: anonymized discovery findings, proposal excerpts, install stories, before-and-after workflow snapshots, and results. When it has content, the `lesson-builder` agent pulls examples from here, especially for units u6 (how the best companies use AI) and the Module 3 method units, because learning our real cases doubles as learning our pitch.

**Current status: empty.** Until this folder is populated, lesson-builder should use live web-researched examples instead and say nothing to the learner about a case bank.

## Rules for adding material

- Sanitize everything: no client names, no identifying details, no confidential numbers unless the client has approved sharing them.
- One case per file, markdown, named like `case-real-estate-advisory.md`.
- Each case states: the business type, the problem, what we did, and the result, in plain language a lesson can quote.
